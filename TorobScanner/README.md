### تغییرات نسخه ۲.۱ (۵ سایت جدید)
- ۵ سایت جدید تحلیل و اضافه شدند (سیلاین، کافه‌کالا، کافه‌این‌شاپ، کافئین‌اکسپرس، قهوه ننجون)
- **ForceTryPagination**: برای سایت‌هایی که لینک صفحه‌بندی ندارند اما /page/N/ کار می‌کند
- **محافظ محصول تکراری**: صفحه‌ای که هیچ محصول جدیدی ندارد → پایان خودکار صفحه‌بندی (ضد حلقه بی‌نهایت)
- **پاک‌سازی هوشمند اسم**: حذف پسوند «فروشگاه ...» و ایموجی از اسامی JSON-LD (مثل ننجون)

### موتور اسکن تطبیقی (بهترین ابزار برای هر سایت)
- **۳ استراتژی خودکار**: JSON-LD (Schema.org) → Microdata → DOM هوشمند
- **رجیستری پروفایل**: افزودن سایت جدید = چند خط در `SiteProfile.Known`
- **سام‌کیش**: تست‌شده ۱۲/۱۲ محصول (نسخه قبلی ۹/۱۲)
- سقف قیمت ۱۰۰ میلیارد (قبلاً ۵۰ میلیون — محصولات گران حذف می‌شدند!)
- قیمت بدون جداکننده هزارگان هم پشتیبانی می‌شود
- بلاک خودکار تصاویر/فونت‌ها → سرعت ~۳ برابر
- محافظ حلقه بی‌نهایت صفحه‌بندی

## ➕ افزودن سایت جدید

در `Scrapers/SiteProfile.cs` فقط یک پروفایل اضافه کنید:

```csharp
new SiteProfile
{
    Name = "نام سایت",
    HostContains = "example.com",
    ContainerSelectors = new[] { "li.product" },   // سلکتور کارت
    TitleSelectors = new[] { "h2 a" },              // سلکتور عنوان
    PriceSelectors = new[] { ".price" },            // سلکتور قیمت
    NeedsLoadMore = false,                          // دکمه «بارگذاری بیشتر» دارد؟
    NeedsInfiniteScroll = false                     // اسکرول بی‌نهایت دارد؟
}
```

اگر سلکتورها را ننویسید، موتور Universal خودش بهترین ترکیب را پیدا می‌کند.
