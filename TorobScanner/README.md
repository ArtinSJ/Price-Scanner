# بازارسنج (BazarSanj) — نسخه ۲.۵ «Platinum Glass»

سنجش هوشمند قیمت و رصد رقبای بازار با موتور اسکن تطبیقی چنداستراتژی — با تم لوکس گلس‌مورفیسم پلاتینیومی.

## 🚀 اجرای پروژه

```
dotnet restore
dotnet build
dotnet run
```

> **پیش‌نیاز کرومیوم** (فقط بار اول): در پوشه پروژه دستور زیر را اجرا کنید:
> ```
> npx playwright install chromium
> ```
> (برنامه خودش کرومیوم → Edge → Chrome را امتحان می‌کند و در صورت نیاز نصب خودکار دارد)

## ✨ چه چیزهایی در نسخه ۲.۵ تغییر کرد؟

### تم لوکس Platinum-Glass (بازطراحی کامل UI)
- **گلس‌مورفیسم پلاتینیومی** به سبک Apple Vision Pro: شیشه‌های مات روی پس‌زمینه‌ی ابیس + سحابی‌های نرم
- **فونت فارسی Vazirmatn** باندل‌شده (۵ وزن: Light تا Bold — داخل exe جاسازی می‌شود)
- **اعداد فارسی** در همه‌جا (قیمت‌ها، آمار، پیشرفت) + زمان نسبی («۲ ساعت پیش»)
- **تم سراسری یکدست** برای همه پنجره‌ها و کنترل‌ها: دکمه، ورودی، ComboBox، دیتاگرید، اسکرول‌بار باریک، ToolTip و…
- **انیمیشن‌های متعادل**: ورود نرم پنجره‌ها، hover شیشه‌ای دکمه‌ها، بالا آمدن کارت‌ها — بدون سنگینی
- **کارتهای آماری بنتو** با گرادیان ایریدسنت + نشانگر تغییر قیمت به‌صورت حباب‌های رنگی
- **حالت خالی (Empty State)** با دکمه‌ی شروع سریع
- **پرفورمنس**: سایه‌ی ثابت روی تک‌تک کارت‌ها حذف شد (گلو فقط هنگام hover) — لیست حتی با صدها محصول روان است

### پنجره واقعاً resizable شد! 
- پنجره اصلی و پنل مدیریت حالا از لبه‌ها قابل تغییر اندازه هستند (WindowChrome)
- دکمه **حداکثر/بازگردانی** + دابل‌کلیک روی نوار عنوان + Aero Snap ویندوز
- قبلاً پنجره borderless هیچ‌کدام از این‌ها را نداشت

## ➕ افزودن سایت جدید

در `Scrapers/SiteProfile.cs` فقط یک پروفایل اضافه کنید:

```csharp
new SiteProfile
{
    Name = "نام سایت",
    HostContains = "example.com",
    ContainerSelectors = new[] { "li.product" },   // سلکتور کارت
    TitleSelectors = new[] { "h2 a" },              // سلکتور عنوان
    PriceSelectors = new[] { ".price" },            // سلکتور قیمت
    NeedsLoadMore = false,                          // دکمه «بارگذاری بیشتر» دارد؟
    NeedsInfiniteScroll = false                     // اسکرول بی‌نهایت دارد؟
}
```

اگر سلکتورها را ننویسید، موتور Universal خودش بهترین ترکیب را پیدا می‌کند.
